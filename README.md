# PkgDrop updates

This repository hosts the signed public update feed and release artifacts for PkgDrop.

- Update feed: `https://updates.kastrup.pro/appcast.xml`
- Installer: `https://updates.kastrup.pro/releases/v0.3.0/PkgDrop-0.3.0.pkg`
- Sparkle update: `https://updates.kastrup.pro/releases/v0.3.0/PkgDrop-0.3.0.zip`

Release artifacts are Developer ID signed and notarized by Apple. The Sparkle update archive and feed are additionally protected by Sparkle EdDSA signatures.
