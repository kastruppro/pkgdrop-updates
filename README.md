# kastrup.pro app updates

This repository hosts signed public update feeds and release artifacts for kastrup.pro macOS apps. Each app uses its own path so the shared update domain can serve additional apps later.

## PkgDrop

- Product site: `https://pkgdrop.kastrup.pro`
- Update feed: `https://updates.kastrup.pro/pkgdrop/appcast.xml`
- Installer: `https://updates.kastrup.pro/pkgdrop/releases/v0.3.0/PkgDrop-0.3.0.pkg`
- Sparkle update: `https://updates.kastrup.pro/pkgdrop/releases/v0.3.0/PkgDrop-0.3.0.zip`

Release artifacts are Developer ID signed and notarized by Apple. The Sparkle update archive and feed are additionally protected by Sparkle EdDSA signatures.
